# Personal Portfolio - Assignment 1

## Project Description

This project is a responsive personal portfolio website created for Web Engineering Assignment 1. The website introduces me as a Computer Science student and presents my skills, projects, and contact information.

The portfolio was developed using HTML, CSS, and JavaScript. It is designed to work across desktop, tablet, and mobile screen sizes and includes interactive features such as a dark/light theme toggle and contact form feedback.

## Features

- About Me section with a short introduction and tagline
- Skills section
- Projects section with project descriptions
- Contact form with Name, Email, and Message fields
- Dark/light theme toggle
- Saved theme preference using localStorage
- Smooth scrolling navigation
- Responsive layout for desktop, tablet, and mobile devices
- Automatic copyright year
- Semantic and accessible HTML structure

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Flexbox
- CSS Grid
- Media Queries
- Git
- GitHub

## How to Run the Project Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using a web browser or the Live Server extension.
4. Navigate through the About, Skills, Projects, and Contact sections.
5. Use the theme toggle button to switch between light and dark modes.
