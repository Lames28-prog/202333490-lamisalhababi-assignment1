# AI Usage Report

## 1. Tools Used and Use Cases

### ChatGPT

I used ChatGPT as an AI-assisted development tool while completing this assignment.

I used ChatGPT for:

- Understanding the assignment requirements.
- Planning the project folder structure.
- Receiving suggestions for semantic HTML structure.
- Receiving CSS suggestions for responsive layouts.
- Understanding how Flexbox, CSS Grid, and media queries can be used.
- Receiving JavaScript suggestions for the dark/light theme toggle.
- Understanding how `localStorage` can preserve a user's theme preference.
- Implementing contact form feedback without a backend.
- Reviewing code structure and accessibility considerations.
- Receiving suggestions for creating lightweight SVG project illustrations.
- Receiving assistance with project documentation.

Rather than using AI only to generate a finished website, I worked through the project in stages and reviewed the purpose of the HTML, CSS, and JavaScript used in each stage.

## 2. Benefits and Challenges

### Benefits

Using AI helped me organize the assignment into smaller development steps. It also helped explain unfamiliar or less familiar parts of the code and provided suggestions for creating a responsive and organized website.

AI was particularly useful when working with responsive CSS, JavaScript event handling, project illustrations, and documentation.

### Challenges

AI-generated suggestions still needed to be reviewed because a suggestion may not always match the exact assignment requirements or project structure.

Another challenge was making sure that I understood the code instead of simply copying it. I reviewed the suggested code, tested its behavior, and connected each part to the assignment requirements.

During development, I also encountered issues with external project images not loading correctly. After reviewing and testing alternatives, I used inline SVG illustrations to provide lightweight project visuals without relying on external image paths.

## 3. Learning Outcomes

During this assignment, I developed a better understanding of:

- Structuring a webpage using semantic HTML.
- Separating HTML, CSS, and JavaScript into different files.
- Using Flexbox and CSS Grid for layouts.
- Using media queries for responsive web design.
- Using JavaScript event listeners for user interactions.
- Using `localStorage` to save browser preferences.
- Handling a form interaction without requiring a backend.
- Understanding how inline SVG can be used to create lightweight graphics without external image files.
- Organizing a web development project using folders.
- Using Git and GitHub to maintain project history.
- Using AI as a development assistant while still reviewing and understanding the resulting code.

## 4. Responsible Use and Modifications

I reviewed the AI-assisted suggestions before using them in my project. I used the assignment requirements to decide which suggestions were appropriate and organized the code according to the required project structure.

I also reviewed explanations of the generated HTML, CSS, JavaScript, and SVG elements so that I could understand the purpose of the code being added.

During development, I tested the suggested solutions and made changes when necessary. For example, the project visuals were changed to inline SVG illustrations after external image files caused loading issues.

The AI-generated suggestions were used as development assistance rather than as a substitute for understanding the assignment. The final project was reviewed and tested to make sure that its features worked correctly and that it met the assignment requirements.
